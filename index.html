Method

How this benchmarking works

This report does not run a new live harness. It compiles vendor launch tables and independent boards, then tells you when those two disagree — and what that means for a real workload.

What “benchmarking” means here

A benchmark is a frozen task suite with a scoring rule. For language models in 2026 that usually means: give the model a repo, a terminal, a desktop, or an exam; let it use tools (or not); count resolved tasks, pass@1, or pairwise Elo. The number is only as good as the protocol — the agent scaffold, timeout, context window, thinking effort, and whether safeguards were left on. We therefore never collapse the field into one “IQ.” We show the protocol next to the score, mark the best cell in this ten-model set in gold, and leave unpublished splits as dashes so specialists are not fake-ranked at zero.

Sources & limits

Compiled professional brief. Re-run your own workload before a purchase.

Harness choice (Claude Code, mini-swe-agent, Terminus, OpenClaw) moves agent scores by more than most model-to-model gaps. Effort levels (max / xhigh / high) are not equivalent across labs. Claude Fable 5.1 and Mythos 5.1 share weights; the published gap on Terminal-Bench 4.0 (55.8 vs 60.9) is largely safeguard policy. Restricted cyber models are scored on completion/refusal and specialist gyms, not SWE-Pro. Browser support: modern evergreen Chrome, Edge, Firefox, Safari (iOS 15+), Samsung Internet, and Opera. Charts require JavaScript; the tables and score cards remain readable if a chart library is blocked.
